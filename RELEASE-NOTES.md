Pulse 2.3 refreshes the interface and Friends.

- Compact header, calmer colors, clearer type and roomier navigation.
- Animated startup screen and soft hover/click feedback; respects Windows reduced-motion settings.
- Larger friend rows with profile pictures and available game activity.
- Selected-friend preview with quick Join game and View profile actions.
- Background avatar loading with a bounded memory cache and fallback portraits.

If Roblox hides a game, Pulse shows “Game not shared”. Joining remains handled by the signed-in Roblox client.
