# Pulse Browser Companion (Test)

The browser companion pairs your existing Roblox browser session with the Windows Pulse test app for account identification, avatar previews and confirmed outfit saves.

The Chrome Web Store listing is being prepared and is not yet available for installation. A compatible Avatar Studio test build is required; the stable Pulse release is not sufficient.

## Windows test build

[Download Pulse Avatar Studio for Windows x64](https://github.com/Paralied/PulsePublic/releases/tag/companion-test-436e101).

Extract the ZIP into a separate folder and run **Pulse.exe** without renaming it. This prerelease uses isolated test settings and does not replace the stable update channel.

Once the companion extension is available, sign in on roblox.com, then open **Avatar Studio > Connect browser** in Pulse. Copy the pairing code into the extension, choose **Pair with Pulse**, and return to Pulse to finish connecting. Keep the extension tab open. Reconnect after switching Roblox accounts.
