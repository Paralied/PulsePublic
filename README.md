# Pulse

Windows Roblox companion.

[Download releases](https://github.com/Paralied/PulsePublic/releases)

Release builds will appear here after the private build workflow is configured and run. This repository contains public downloads and release notes; development source is kept privately.

Pulse checks this repository for stable updates. Downloads are verified against GitHub's SHA-256 asset digest before installation, and updating asks you to restart Pulse.
